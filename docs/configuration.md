# Configuration reference

The collector is configured via `.env` and Compose. **Do not add secrets to Git.**

## Source adapters

- `SENTINEL_HOST_IP`: dedicated Sentinel host's LAN IPv4; mTLS SAN must match.
- `SENTINEL_API_TOKEN_FILE`, `SENTINEL_INGEST_TOKEN_FILE`: distinct file
  credentials generated by `bootstrap.sh` into `secrets/`; never commit or print them.
  The old raw token environment variables are accepted only for legacy
  non-Compose deployments and cannot be mixed with the respective `_FILE` input.
- `SENTINEL_ADGUARD_ENABLED`: false unless the query-log API and read credentials are configured.
- `SENTINEL_CROWDSEC_ENABLED`: false unless read-only decisions API is reachable.
- `SENTINEL_BIND_ADDR`: standalone server defaults to `127.0.0.1:8080`. The Compose service listens inside its container and publishes the API on host loopback.
- `SENTINEL_ALLOW_HTTP_UPSTREAMS`: false by default. Explicitly opting into insecure transport
  puts credentials at risk and enables both API adapters to accept HTTP.
- `SENTINEL_DETECTION_*`, `SENTINEL_RULE_*`: deterministic detection thresholds (see `.env.example`).

## Harness/model options

- `SENTINEL_HARNESS_READ_TOKEN_FILE`: server/agent file path to read-only bridge credential;
  bootstrap stores it at `secrets/harness_read_token`, group-readable only in containers.
- `SENTINEL_HARNESS_REPORT_TOKEN_FILE`: distinct credential permitting only report storage.
- `SENTINEL_API_URL`: agent-only fixed Sentinel base origin, default `http://sentinel:8080/`.
- `SENTINEL_OLLAMA_URL`: model server's base origin, default `http://ollama:11434/`.
  For an externally hosted model enable `deploy/compose.remote-ollama.yaml` explicitly,
  restrict remote egress by host firewall, and use HTTPS by default.
- `SENTINEL_OLLAMA_CA_FILE`: optional model HTTPS trust root mounted under `/etc/sentinel/upstreams/`.
- `SENTINEL_ALLOW_HTTP_MODEL`: false by default. Setting true explicitly allows **only private-LAN IP model endpoints** over unencrypted HTTP (telemetry can be observed in transit).
- `SENTINEL_LLM_MODEL`: actual installed tool-calling model name, default `qwen3:4b`.

The optional `ollama` Compose profile is for users with sufficient RAM/GPU. Do not
publish 11434 or run model administration on a public interface. On a small telemetry
VM, run Ollama elsewhere and configure only the model URL.

## Multi-instance and reuse

Change the Compose project name (`name:`), volume names, host port, TLS host/IP
and tokens for each deployment. Do not share SQLite files or secrets across instances.
For non-OPNsense environments the Vector source/parser must be adapted; CrowdSec and
AdGuard remain optional. The agent's read-only tool contract works with any feed that
can normalize to `security_events`; unsupported sources do not produce fictitious data.

Config validation intentionally fails on malformed secrets and unsupported URLs.
Avoid disabling TLS verification or increasing query budgets without a security review.
